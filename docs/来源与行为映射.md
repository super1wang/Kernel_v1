## 必须承接的具体修复

- Executor 的五组测试覆盖工作/完成恰一次、异常容纳、停止后拒绝、worker 防死锁、并发停止串行化。
- `kernel_shutdown_tests.cpp` 覆盖停止失败可重试、超时/非法超时不假完成、并发调用不能绕过排空、配置/启动失败及模块停止失败也要先最终排空再释放执行器。
- SQLite Host session 覆盖路径别名、同时争抢、故障代理、显式刷盘配置及漂移复核、内存能力标记、事务中拒绝独占准入；真实双进程材料一起保留。
- M0 边界扫描补上原扫描未纳入的 `src/**/*.h/hpp/ipp/inl/tpp`，并加入核心反向依赖、公开头引用私有头等负例。它是静态保守检查，不能替代 M1 安装消费和 M8 链接审计。

具体迁入时在相应交付文档记录实际目标文件、修改理由和新测试证据。M0 不声称表中所有机制已迁移。
